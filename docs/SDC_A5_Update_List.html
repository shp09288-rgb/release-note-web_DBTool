1CIM

PMS #4552 CIM 불안정

현상
설비 가동 중 CIM 무응답으로 Glass 반송이 진행되지 않고, CIM 재시작으로만 복구되던 현상
개선
XEA
  • Glass 반송 중 GlassExchangeState 조회 주기 변경 (0.5초 → 5초)
XES
  • TCP Keepalive 파라미터 조정으로 연결 끊김을 5초 이내 감지
  • 응답 대기 구간에서도 끊김을 감지하도록 LinkWatchdog 추가
  • 재연결 시 Control State가 Remote에서 Offline으로 변경되던 문제 수정
    Control State 주체를 XEA로 통일

PMS #4900 Shutter Door 상태 전달

현상
Shutter Door가 동작 중인 상태에서도 Door Open으로 전달되어,
개방이 완료되기 전에 반송이 진행될 수 있던 현상
개선
XEA
  • Door 상태를 Open / Closed / 동작 중으로 구분하여 Contact Point 전달
  • 동작 중이거나 판별되지 않는 상태에서는 Open, Closed 모두 전달하지 않도록 변경
