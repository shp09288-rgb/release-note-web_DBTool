Clamp Open / Close 동작 완료 감지와 Servo On 확인이 지연됨
개선
XEService
  • Motor 모니터링 로그 조회를 일괄 조회로 병합 (Polling 사이클당 9회에서 최대 4회)

파크 검증

참고

PMS #4842 Ionizer 알람 발생 조건 및 FDC Upload 공통 반영현장 확인

현상
Shutter Door Open 으로 Ionizer Controller 전원이 차단되는 구간에 통신이상 알람 발생
FDC 항목 중 일부 Head Runtime 미보고
Number of Heads 를 4 미만으로 설정 시 Head 간 데이터가 한 칸씩 밀림
개선
XEA
  • Ionizer FDC VID 매핑을 고정 4채널에서 XES 응답 Head 수 기준으로 변경
  • Head Runtime, Run State, State, Over Time VID 인덱스를 실연결 Head 수 기준으로 연속 배치
  • Shutter Door Open 시 Ionizer 전원 Off 알람(40044) 차단
  • Ionizer 통신이상 알람(140005)을 Controller 전원 On 상태에서만 발생하도록 변경
XEService
  • Number of Heads 설정 범위를 1 에서 4 로 제한하고 Head 데이터 파싱 개선
  • 수신 패킷 검증 강화 (체크섬 범위 고정, 손상 페이로드 폐기, 패킷 길이 검증)
  • Head 상태 3회 연속 동일 판정 시에만 반영
  • Head 미연결 알람을 매 Polling 반복 발생에서 상태 변화 시 1회 발생으로 변경
  • Head Alarm 수신 값 보존 (Over Current, Communication Out 이 Head Fail 로 병합되던 현상 개선)
검증
판단
Head 수 설정이 실제와 일치해야 하므로 설정값 확인이 필요합니다.
확인 방법
XES DB Ionizer NumberOfHeads 값이 실제 연결 Head 수와 일치하는지 확인
XEA Ionizer 화면의 Head 수 표시 확인
참고
Ionizer 미사용 설비이면 확인이 필요하지 않습니다. 신규 Alarm 140005 는 4. 신규 Alarm 표를 참고해 주시기 바랍니다.
